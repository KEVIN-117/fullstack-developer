# Tópico 5.3: DevSecOps y Auditorías de Seguridad

## 🎯 Objetivo de Aprendizaje
Asegurar el ciclo de entrega de software mediante análisis estático de imágenes Docker con Trivy y realizar auditorías de hardening sobre el sistema operativo físico Debian utilizando Lynis.

## 📋 Checklist de Conceptos a Dominar
- [ ] Explicar qué es una vulnerabilidad CVE (Common Vulnerabilities and Exposures) y cómo se clasifican (CVSS Score).
- [ ] Diferencia entre análisis estático (SAST - sobre la estructura inerte del contenedor) y análisis dinámico o de configuración de host.
- [ ] Comprender cómo funcionan los escaneos de capas de Docker en busca de dependencias inseguras.
- [ ] Conocer las áreas clave de auditoría de Lynis: Bootloaders, Kernel, Cuentas de usuarios y Firewalls.
- [ ] Entender las pautas de endurecimiento recomendadas por los CIS Benchmarks (Center for Internet Security).

## 📚 Conceptos Mínimos a Estudiar
*   **CVSS (Common Vulnerability Scoring System):** Sistema de métricas estándar para calificar la severidad de vulnerabilidades de seguridad de software en una escala del 0 al 10 (Critical $\ge$ 9.0, High $\ge$ 7.0).
*   **Escaneo Estático de Imágenes (Trivy):** Analiza las firmas de los paquetes instalados en el sistema operativo base de la imagen (ej: OpenSSL de Alpine) y las dependencias de código del desarrollador contra las bases de datos de vulnerabilidades CVE conocidas.
*   **CIS Benchmarks:** Guías internacionales de configuración de seguridad de mejores prácticas para blindar sistemas operativos, bases de datos y orquestadores contra intrusiones. Lynis las evalúa localmente para dar recomendaciones puntuales sobre Debian.

## 🚀 Actividades Prácticas Realizadas
1. Instalar y ejecutar Lynis en Debian físico (`lynis audit system`) e identificar sugerencias de hardening.
2. Integrar Trivy en el workflow de CI/CD del Módulo 2 para analizar la imagen de Docker del backend.
3. Configurar Trivy para fallar con código de error 1 si se detectan vulnerabilidades críticas.
4. Aplicar al menos 3 mejoras en la configuración de Debian sugeridas en el reporte final de Lynis.

## 🔍 Comandos de Diagnóstico Útiles
*   `trivy image --severity HIGH,CRITICAL <nombre_imagen>`: Escanea una imagen Docker local y detalla todas las vulnerabilidades críticas y parches disponibles.
*   `sudo lynis audit system`: Ejecuta la suite completa de auditoría de seguridad sobre el servidor físico Debian y calcula el Hardening Index actual.
*   `cat /var/log/lynis.log`: Muestra logs de auditoría interna generados por Lynis.
