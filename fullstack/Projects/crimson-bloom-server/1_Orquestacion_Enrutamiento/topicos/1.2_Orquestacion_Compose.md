# Tópico 1.2: Orquestación con Docker Compose

## 🎯 Objetivo de Aprendizaje
Definir infraestructuras multi-contenedor complejas de forma declarativa e interactiva utilizando archivos YAML de Docker Compose.

## 📚 Conceptos Mínimos a Estudiar
*   **Redes Bridge en Docker:** Red virtual privada en la que los contenedores pueden comunicarse entre sí usando el nombre del servicio de Compose como DNS local (ej. Nginx puede redirigir tráfico a `api-backend` resolviendo automáticamente la IP interna cambiante).
*   **Almacenamiento Persistente:**
    *   *Volume:* Gestionado por el motor de Docker en `/var/lib/docker/volumes/`. Ideal para producción por rendimiento y desacoplamiento del sistema operativo anfitrión.
    *   *Bind Mount:* Enlace directo a un directorio físico del Host Debian. Excelente para desarrollo o inyección de archivos de configuración como `nginx.conf`.
*   **Sintaxis del YAML de Compose:** Conceptos de servicios (`services`), puertos mapeados (`ports` - expone al host físico) y puertos expuestos (`expose` - solo visible a contenedores en la red compartida).

## 🚀 Actividades Prácticas Realizadas
1. Creada una red bridge interna personalizada llamada `homelab_network` en un archivo `docker-compose.yml`.
2. Declarado un contenedor web estático simple aislado de la red externa sin mapeo de puertos (`expose` únicamente).
3. Configurada la persistencia de datos mediante volúmenes para que el contenido web sea leído de forma dinámica.
4. Desplegada la pila completa usando el CLI de Compose (`docker compose up -d`).

## 🔍 Comandos de Diagnóstico Útiles
*   `docker compose up -d`: Construye, crea y arranca todos los servicios definidos en el archivo YAML en segundo plano.
*   `docker compose down`: Detiene y elimina los contenedores, redes y volúmenes temporales creados por el Compose.
*   `docker compose ps`: Lista el estado actual de los contenedores orquestados en el directorio local.
*   `docker volume ls`: Muestra todos los volúmenes de datos virtuales persistentes creados en Docker.
*   `docker network ls`: Muestra las redes virtuales bridge activas en el Host Debian.
