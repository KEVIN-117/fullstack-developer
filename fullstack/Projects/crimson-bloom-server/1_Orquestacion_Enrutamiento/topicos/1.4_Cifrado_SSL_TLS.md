# Tópico 1.4: Cifrado SSL/TLS Local

## 🎯 Objetivo de Aprendizaje
Asegurar la privacidad e integridad de los datos en tránsito hacia el Home Lab mediante la implementación de cifrado asimétrico (HTTPS) con certificados locales.

## 📋 Checklist de Conceptos a Dominar
- [ ] Explicar cómo funciona el cifrado simétrico y asimétrico en el protocolo HTTPS.
- [ ] ¿Qué es una Autoridad de Certificación (CA) de confianza y cómo valida los dominios locales?
- [ ] Conocer las directivas de seguridad TLS en Nginx (`ssl_protocols`, `ssl_ciphers`).
- [ ] Diferencia entre TLS v1.2 y el protocolo simplificado de alto rendimiento TLS v1.3.
- [ ] Entender el concepto de "Apretón de manos" (TLS Handshake) y negociación de cifrado.

## 📚 Conceptos Mínimos a Estudiar
*   **TLS Handshake (Apretón de manos):** El proceso mediante el cual el cliente y el servidor web negocian el cifrado, se autentica la identidad del servidor mediante certificados digitales, y se genera una clave de cifrado simétrica secreta temporal para cifrar la sesión actual.
*   **TLS v1.3:** Última especificación del protocolo de encriptación web. Reduce la latencia de conexión (handshake toma 1 ciclo de ida y vuelta en lugar de 2 en TLS v1.2) y descarta algoritmos antiguos vulnerables de cifrado.
*   **Autoridades de Certificación (CA):** Entidad de firma digital. Para entornos locales, usar `mkcert` permite inyectar una Autoridad de Certificación raíz de confianza en el navegador de tu computadora local para que el dominio ficticio `homelab.local` sea considerado seguro sin emitir alertas de seguridad.

## 🚀 Actividades Prácticas Realizadas
1. Instalado `mkcert` o configurado `openssl` para actuar como CA local.
2. Generado el par de claves SSL (`homelab.local.crt` y `homelab.local.key`).
3. Montados los certificados generados dentro del contenedor de Nginx en la ruta `/etc/nginx/certs/`.
4. Configurado Nginx para redirigir forzosamente todo tráfico HTTP (puerto 80) a HTTPS (puerto 443).
5. Importado el certificado raíz de la CA local en el navegador de tu máquina cliente de desarrollo.

## 🔍 Comandos de Diagnóstico Útiles
*   `openssl x509 -in cert.crt -text -noout`: Lee e imprime el contenido de un certificado SSL para verificar vigencia y dominios permitidos.
*   `curl -iv https://homelab.local`: Realiza una petición HTTPS detallando el proceso de handshake y mostrando las cabeceras TLS negociadas.
*   `mkcert -install`: Instala la CA local de confianza en los almacenes de certificados del sistema operativo actual.
