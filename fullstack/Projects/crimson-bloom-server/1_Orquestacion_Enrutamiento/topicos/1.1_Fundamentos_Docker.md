# Tópico 1.1: Fundamentos de Docker

## 🎯 Objetivo de Aprendizaje
Comprender los principios del aislamiento de procesos en Linux mediante contenedores de Docker y dominar la creación, control y monitoreo de instancias aisladas.

## 📋 Checklist de Conceptos a Dominar
- [ ] Explicar la diferencia entre una Máquina Virtual (emulación de hardware) y un Contenedor (compartición de Kernel).
- [ ] Comprender cómo funcionan los *Namespaces* y *Control Groups (cgroups)* en el Kernel de Linux para aislar recursos.
- [ ] ¿Cómo funciona el sistema de archivos de capas superpuestas (OverlayFS/UnionFS) en Docker?
- [ ] Explicar el ciclo de vida de un contenedor (Created, Running, Paused, Stopped, Exited).
- [ ] Conocer la arquitectura cliente-servidor de Docker (CLI, REST API, Dockerd Daemon).

## 📚 Conceptos Mínimos a Estudiar
*   **Namespaces de Linux:** Permiten aislar lo que el contenedor puede ver. Tipos: `PID` (procesos), `NET` (redes), `MNT` (montajes), `IPC` (comunicación), `UTS` (hostname), `USER` (usuarios).
*   **Control Groups (cgroups):** Limitan y miden cuántos recursos del sistema operativo (RAM, CPU, I/O de disco) puede consumir un contenedor.
*   **OverlayFS:** Sistema de archivos de copia en escritura (copy-on-write). Permite que múltiples contenedores compartan una misma base de imagen de solo lectura y guarden sus modificaciones en una capa superior (Writable Layer) muy ligera.

## 🔍 Comandos de Diagnóstico Útiles
*   `docker ps -a`: Lista todos los contenedores en el sistema (activos e inactivos).
*   `docker logs -f <container_name>`: Sigue la salida de consola (logs) de un contenedor en tiempo real.
*   `docker exec -it <container_name> sh`: Abre una terminal interactiva (shell) dentro de un contenedor en ejecución.
*   `docker inspect <container_name>`: Muestra información detallada en formato JSON sobre la configuración de red y volúmenes de un contenedor.
*   `docker stats`: Monitorea el consumo de CPU, RAM y red de todos los contenedores activos.
