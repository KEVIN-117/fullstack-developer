# Tópico 4.3: Serving de Modelos con FastAPI

## 🎯 Objetivo de Aprendizaje
Desarrollar y poner en producción una API web de inferencia síncrona en tiempo real cargando dinámicamente el modelo registrado desde el servidor de MLflow.

## 📋 Checklist de Conceptos a Dominar
- [ ] Explicar la diferencia de arquitectura y requerimientos entre inferencia síncrona (tiempo real) y asíncrona (batch).
- [ ] ¿Cómo utilizar esquemas Pydantic para validar los tipos de datos entrantes de la petición en FastAPI?
- [ ] Entender las fases de inicio de la API y cómo almacenar el modelo en memoria del proceso de forma estática para acelerar respuestas.
- [ ] ¿Cómo gestionar fallbacks de carga si el servidor de MLflow no responde durante la inicialización de la API?
- [ ] Conocer qué es el concepto de serialización de modelos (Pickle, ONNX) y sus implicaciones de seguridad.

## 📚 Conceptos Mínimos a Estudiar
*   **Real-time Inference Serving:** Exponer el modelo entrenado detrás de una API síncrona. La API debe estar optimizada para responder con sub-segundo de latencia (menos de 100ms es el estándar), lo que obliga a tener el modelo cargado previamente en memoria y no leer del disco en cada petición.
*   **Pydantic Schemas:** Biblioteca de parseo y validación de tipos de datos en Python. Garantiza que las peticiones entrantes tengan el formato y los valores válidos esperados (ej. montos estrictamente positivos) antes de que la petición sea procesada por el modelo.
*   **ONNX (Open Neural Network Exchange):** Formato de representación de modelos abierto. Permite entrenar un modelo en un lenguaje (ej: Python/Scikit-learn) y exportarlo a un archivo portable binario estructurado para correr inferencias muy rápidas en otros runtimes de ejecución sin dependencias pesadas.

## 🚀 Actividades Prácticas Realizadas
1. Programada la API RESTful de inferencia con FastAPI en el archivo `serve.py`.
2. Definido el esquema de validación `FacturaInput` mediante Pydantic.

## 🔍 Comandos de Diagnóstico Útiles
*   `uvicorn serve:app --reload --port 8000`: Lanza la API FastAPI de desarrollo local con recarga en caliente ante modificaciones del código.
*   `curl -X POST http://localhost:8000/predict -H "Content-Type: application/json" -d '{"monto": 15000.0, "antiguedad_proveedor": 1, "categoria": "Equipos"}'`: Envía datos de prueba localmente para testear la respuesta de predicción.
