# Tópico 3.1: Almacenamiento Relacional (PostgreSQL) y No Relacional (Redis)

## 🎯 Objetivo de Aprendizaje
Configurar motores de base de datos PostgreSQL (para transacciones y datos estructurados) y Redis (para almacenamiento en memoria de alta velocidad y caching) de manera segura y persistente.

## 📋 Checklist de Conceptos a Dominar
- [ ] Explicar el principio de atomicidad, consistencia, aislamiento y durabilidad (propiedades ACID) en bases de datos relacionales.
- [ ] Comprender qué es la normalización de esquemas y cómo diseñar restricciones de unicidad (`UNIQUE`) e integridad referencial (llaves foráneas).
- [ ] ¿Cómo funciona Redis en memoria y qué implicaciones tiene la persistencia opcional (RDB y AOF)?
- [ ] Conocer las estructuras de datos de Redis: Strings, Sets (clave para deduplicar) e inyección de expiración (TTL).
- [ ] Conocer el uso del tipo de datos estructurado JSONB en PostgreSQL y sus ventajas sobre el formato JSON plano.

## 📚 Conceptos Mínimos a Estudiar
*   **Transacciones ACID:** Garantizan que todas las operaciones dentro de un bloque SQL se ejecuten con éxito o se reviertan por completo (rollback) en caso de fallo, manteniendo la consistencia de la base de datos física.
*   **Redis Data Persistence:** Redis es en memoria pero ofrece dos métodos de persistencia física:
    *   *RDB (Redis Database Backup):* Capturas del estado en disco a intervalos definidos (rápido pero con posibilidad de perder datos recientes).
    *   *AOF (Append Only File):* Registro de cada comando de escritura recibido en disco (seguro pero más lento y genera archivos grandes).
*   **Esquemas Relacionales Normalizados:** Dividir tablas para evitar redundancias (ej. separar información del proveedor de las facturas transaccionales) utilizando índices en columnas consultadas con frecuencia para acelerar lecturas.

## 🔍 Comandos de Diagnóstico Útiles
*   `docker exec -it postgres-db psql -U airflow_user -d airflow_db`: Accede de forma interactiva a la terminal CLI de PostgreSQL.
*   `docker exec -it redis-cache redis-cli`: Abre la consola interactiva de Redis en vivo.
*   `redis-cli ping`: Devuelve `PONG` si el servicio en memoria responde correctamente.
*   `\dt`: Comando dentro de psql para listar todas las tablas creadas en la base de datos actual.
