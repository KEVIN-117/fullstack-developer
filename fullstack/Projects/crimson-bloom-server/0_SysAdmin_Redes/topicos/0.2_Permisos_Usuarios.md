# Tópico 0.2: Permisos de Linux y Administración de Usuarios

## 🎯 Objetivo de Aprendizaje
Aprender a gestionar usuarios y grupos en Linux y dominar el sistema de permisos de archivos y directorios bajo el estándar POSIX.

## 📋 Checklist de Conceptos a Dominar
- [ ] Comprender la estructura de los archivos `/etc/passwd` y `/etc/shadow`.
- [ ] Dominar la representación binaria y octal de los permisos de lectura (`r`), escritura (`w`) y ejecución (`x`).
- [ ] Diferencia entre privilegios del superusuario `root` y la delegación segura mediante el comando `sudo`.
- [ ] Explicar la directiva de seguridad del archivo `/etc/sudoers`.
- [ ] Conocer qué es y cómo configurar permisos especiales (SUID, SGID y Sticky Bit).

## 📚 Conceptos Mínimos a Estudiar
*   **Permisos POSIX:** Lectura (`r`=4), Escritura (`w`=2), Ejecución (`x`=1). Se aplican para tres entidades: Propietario (User), Grupo (Group) y Otros (Others). Ejemplo: `755` significa rwx para user, rx para group y rx para others.
*   **Gestión de Privilegios:** Entender cómo opera el archivo `/etc/sudoers` para delegar privilegios de administrador de forma restringida (usando `visudo` para evitar errores catastróficos que dejen inservible el sistema).
*   **Permisos Especiales:**
    *   *SUID:* El archivo se ejecuta con los permisos del propietario del archivo.
    *   *SGID:* El archivo se ejecuta con los permisos del grupo del archivo.
    *   *Sticky Bit:* Solo el propietario de un archivo dentro de una carpeta (como `/tmp`) puede borrarlo.

## 🚀 Actividades Prácticas Realizadas
1. Creado el usuario administrador del Home Lab: `sudo adduser homelab_admin`.
2. Otorgados permisos de administrador al nuevo usuario agregándolo al grupo `sudo`.
3. Comprobado el acceso al comando sudo con el nuevo usuario (`sudo whoami` debe responder `root`).
4. Practicado el cambio de dueños y permisos en archivos usando `chmod` y `chown`.

## 🔍 Comandos de Diagnóstico Útiles
*   `ls -la`: Lista los archivos del directorio actual mostrando permisos, propietario y grupo de forma detallada.
*   `groups <usuario>`: Muestra los grupos de seguridad a los que pertenece el usuario.
*   `sudo visudo`: Abre el archivo de configuración `/etc/sudoers` para delegar permisos de forma segura sin peligro de corromper la sintaxis.
*   `chown usuario:grupo archivo`: Cambia el dueño y grupo del archivo.
*   `chmod 600 archivo`: Otorga permisos exclusivos de lectura y escritura al propietario del archivo.
