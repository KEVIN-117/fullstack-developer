# Tópico 0.4: Seguridad Perimetral con UFW

## 🎯 Objetivo de Aprendizaje
Configurar y administrar un cortafuegos local (UFW) para restringir el tráfico entrante del Home Lab aplicando una política restrictiva por defecto.

## 📋 Checklist de Conceptos a Dominar
- [ ] ¿Qué relación existe entre UFW (Uncomplicated Firewall) e iptables/nftables en el kernel de Linux?
- [ ] Comprender el principio de diseño de seguridad "Denegar por Defecto" (Default Deny).
- [ ] Diferencia entre las conexiones orientadas al estado TCP y el protocolo de red no orientado al estado UDP.
- [ ] Entender las reglas de entrada (incoming) vs salida (outgoing) de paquetes de red.
- [ ] Conocer cómo restringir reglas de firewall a IPs o subredes específicas (ej. solo permitir SSH en una subred específica).

## 📚 Conceptos Mínimos a Estudiar
*   **Netfilter e iptables:** Los cortafuegos en Linux interactúan con el framework `Netfilter` del kernel, el cual intercepta y procesa los paquetes de red. UFW es un frontend simplificado para escribir estas complejas reglas de red de forma humana.
*   **Política Default Deny:** Bloquear absolutamente todo tráfico de entrada al Home Lab a menos que haya una regla explícita que lo autorice. Esto mitiga que puertos de bases de datos o servicios experimentales queden expuestos al router y a internet por descuido.
*   **TCP vs UDP:**
    *   *TCP (Transmission Control Protocol):* Orientado a la conexión (handshake 3 vías), garantiza entrega de datos. Usado en SSH, HTTP, APIs.
    *   *UDP (User Datagram Protocol):* Sin conexión, rápido, no garantiza entrega. Usado en DNS, streaming, VPNs (WireGuard).

## 🚀 Actividades Prácticas Realizadas
1. Instalado el cortafuegos `ufw` en el servidor Debian local.
2. Definidas las políticas por defecto para denegar entradas y permitir salidas generales.
3. Creadas reglas específicas para habilitar SSH (puerto 22 o puerto alternativo 2022), HTTP (80) y HTTPS (443).
4. Activado el firewall en el sistema operativo y comprobado su estado.

## 🔍 Comandos de Diagnóstico Útiles
*   `sudo ufw status verbose`: Muestra el estado del firewall de forma detallada junto con sus reglas activas.
*   `sudo ufw show added`: Muestra las reglas que han sido agregadas en la cola de configuración de UFW.
*   `sudo ufw allow 80/tcp`: Permite tráfico TCP entrante al puerto 80 (HTTP).
*   `sudo ufw deny from 192.168.1.50`: Bloquea explícitamente todo tráfico entrante proveniente de una dirección IP específica.
*   `sudo ufw enable` y `sudo ufw disable`: Activa o desactiva las reglas de filtrado del firewall en el host Debian.
