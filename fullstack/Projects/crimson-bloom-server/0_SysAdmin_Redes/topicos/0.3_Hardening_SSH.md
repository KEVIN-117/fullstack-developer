# Tópico 0.3: Acceso Seguro vía SSH Hardening

## 🎯 Objetivo de Aprendizaje
Asegurar el protocolo de administración remota SSH contra ataques externos desactivando mecanismos débiles de autenticación y empleando criptografía asimétrica moderna.

## 📋 Checklist de Conceptos a Dominar
- [ ] Diferencia entre criptografía simétrica y asimétrica (par de llaves pública/privada).
- [ ] Por qué el algoritmo Ed25519 es superior a RSA en términos de tamaño de llave y velocidad de cifrado.
- [ ] Entender las consecuencias de seguridad de mantener activo el inicio de sesión por contraseña (`PasswordAuthentication yes`).
- [ ] Conocer las directivas de endurecimiento críticas del archivo `/etc/ssh/sshd_config`.
- [ ] Explicar cómo mitigar ataques de fuerza bruta reduciendo el número de intentos permitidos (`MaxAuthTries`).

## 📚 Conceptos Mínimos a Estudiar
*   **Ed25519 vs RSA:** Ed25519 utiliza criptografía de curva elíptica (Edwards-curve Digital Signature Algorithm), ofreciendo una llave de 256 bits extremadamente segura equivalente a una llave RSA de 3072 bits, pero con firmas más rápidas y menos consumo de CPU.
*   **Hardening del demonio SSH (sshd):** Bloquear el acceso directo al usuario administrador `root` (`PermitRootLogin no`), forzar el uso de llaves criptográficas públicas (`PubkeyAuthentication yes`) y apagar la autenticación clásica por contraseña (`PasswordAuthentication no`).
*   **Gestión de huellas digitales de hosts:** Entender el archivo `~/.ssh/known_hosts` y cómo previene ataques de Man-in-the-Middle (MitM) verificando la huella digital del servidor al conectar.

## 🚀 Actividades Prácticas Realizadas
1. Generado el par de claves Ed25519 en la máquina cliente local (`ssh-keygen -t ed25519`).
2. Copiada la clave pública al servidor Debian (`ssh-copy-id`).
3. Modificada la configuración del demonio SSH (`sshd_config`) para bloquear el login de `root` y desactivar contraseñas.
4. Reiniciado el servicio SSH y validada la restricción intentando acceder con contraseñas.

## 🔍 Comandos de Diagnóstico Útiles
*   `ssh-keygen -y -f ~/.ssh/id_ed25519`: Extrae la clave pública de un archivo de clave privada para verificar correspondencia.
*   `sudo systemctl restart ssh`: Reinicia el servicio daemon SSH en Debian para aplicar cambios de configuración.
*   `sudo sshd -t`: Prueba la sintaxis de la configuración del archivo `/etc/ssh/sshd_config` antes de reiniciar el servicio para evitar bloqueos accidentales.
*   `tail -f /var/log/auth.log`: Monitorea en vivo los intentos de conexión SSH.
