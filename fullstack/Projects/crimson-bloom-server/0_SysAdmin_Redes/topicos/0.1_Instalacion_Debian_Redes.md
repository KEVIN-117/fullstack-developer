# Tópico 0.1: Instalación de Debian Headless y Redes Básicas

## 🎯 Objetivo de Aprendizaje
Instalar Debian Linux en modo minimalista (headless) en un servidor físico y configurar direccionamiento IP estático local para garantizar una dirección persistente en la red local.

## 📋 Checklist de Conceptos a Dominar
- [ ] Comprender qué es una distribución Debian estable y la diferencia entre una imagen Netinst y una imagen completa (DVD).
- [ ] Explicar las implicaciones de rendimiento y seguridad de un servidor Headless (sin GUI).
- [ ] Entender las partes de una IP en la subred local (Dirección IP, Máscara de Red `/24`, Puerta de enlace predeterminada, Servidores DNS).
- [ ] Dominar la lectura de las interfaces de red físicas mediante comandos básicos de Linux.
- [ ] Comprender la estructura de jerarquía de directorios de Linux (FHS - Filesystem Hierarchy Standard).

## 📚 Conceptos Mínimos a Estudiar
*   **Filesystem Hierarchy Standard (FHS):** La organización de carpetas en Linux. Entender qué va en `/etc` (configuración), `/var` (datos variables/logs), `/home` (usuarios), `/bin` y `/sbin` (binarios del sistema).
### 🔑 Conceptos clave

- **Archivos estáticos vs. variables:**
    
    - _Estáticos_: no cambian sin intervención (ej. binarios, librerías).
        
    - _Variables_: cambian constantemente (ej. logs, correos).
        
- **Archivos compartibles vs. no compartibles:**
    
    - _Compartibles_: pueden usarse en varios sistemas (ej. `/usr`).
        
    - _No compartibles_: específicos de un sistema (ej. `/etc`).
        

### 📌 Importancia práctica

- **Administradores**: saben dónde buscar configuraciones y logs.
    
- **Desarrolladores**: escriben software portable entre distribuciones.
    
- **Usuarios**: entienden dónde están sus archivos y programas.
    

En resumen, el **FHS es la “gramática” del sistema de archivos en Linux**, asegurando que cualquier distribución mantenga una estructura coherente y predecible.

|Directorio|Propósito|Ejemplo de contenido|
|---|---|---|
|**/bin**|Binarios esenciales para todos los usuarios|`` `ls` ``, `` `cp` ``, `` `mv` ``|
|**/boot**|Archivos del cargador de arranque|Kernel, `` `grub` ``|
|**/dev**|Archivos de dispositivos|`` `/dev/sda` ``, `` `/dev/null` ``|
|**/etc**|Configuración específica del sistema|`` `passwd` ``, `` `fstab` ``|
|**/home**|Directorios personales de usuarios|`` `/home/kevin` ``|
|**/lib**|Bibliotecas compartidas esenciales|`` `libc.so` ``|
|**/media**|Punto de montaje para medios removibles|USB, CD-ROM|
|**/mnt**|Montajes temporales|discos externos|
|**/opt**|Software adicional|aplicaciones de terceros|
|**/root**|Directorio personal del superusuario|archivos del administrador|
|**/run**|Datos variables en tiempo de ejecución|PID files|
|**/sbin**|Binarios de administración del sistema|`` `fsck` ``, `` `iptables` ``|
|**/srv**|Datos de servicios ofrecidos|páginas web, FTP|
|**/tmp**|Archivos temporales|sesiones, cachés|
|**/usr**|Programas y datos de usuario|`` `/usr/bin` ``, `` `/usr/lib` ``|
|**/var**|Datos variables|logs, colas de impresión, correos|

*   **Direccionamiento IPv4 Privado:** Rangos de red locales (clase C más común en hogares: `192.168.X.X`). Concepto de puerta de enlace (Gateway) que es la IP de tu router.
*   **Servidores DNS (Domain Name System):** Resolución de nombres. Entender el archivo `/etc/resolv.conf` y el uso de DNS públicos como Cloudflare (`1.1.1.1`) o Google (`8.8.8.8`).

## 🚀 Actividades Prácticas Realizadas
1. Descargada la ISO de Debian e instalada en una memoria USB.
2. Instalado el OS Debian headless en la máquina física (marcando solo SSH Server y utilidades del sistema).
3. Identificada la interfaz de red física activa con `ip a`.
4. Configurada la dirección IP fija editando el archivo `/etc/network/interfaces`.
5. Reiniciado el servicio de red (`systemctl restart networking`) y probado ping saliente hacia internet.

## 🔍 Comandos de Diagnóstico Útiles
*   `ip a` o `ip address`: Lista todas las interfaces de red físicas y sus IPs asignadas.
*   `ip route show`: Muestra la tabla de enrutamiento y la IP de la puerta de enlace (Gateway).
*   `ping -c 4 8.8.8.8`: Comprueba la conectividad hacia los servidores DNS de Google.
*   `cat /etc/resolv.conf`: Permite ver los servidores DNS configurados en el sistema local.
