Ahora que has visto cómo los servidores MCP amplían las capacidades de GitHub Copilot, demos el siguiente paso: combinarlos con el modo agente de Copilot. Aquí es donde Copilot va más allá de responder a las preguntas y comienza a actuar como un verdadero colaborador, capaz de planificar, ejecutar y perfeccionar flujos de trabajo.

En esta unidad, aprenderás:

- ¿Qué es el modo agente de Copilot y en qué se diferencia del uso estándar?
- Cómo los servidores MCP mejoran el modo agente conectando Copilot a datos y herramientas externas.
- Los principales beneficios de combinar MCP con modo agente son la automatización y la reducción del esfuerzo manual.
- Cómo aplicar las mejores prácticas para guiar eficazmente a Copilot en flujos de trabajo agentes.

## Cómo usar el servidor MCP de GitHub con Copilot Chat

1. Abre el Copilot Chat en Visual Studio Code y cambia al modo Agente para activar las herramientas MCP Server.
    
2. Haz clic en Select herramientas para ver todas las funcionalidades disponibles del servidor MCP.
    
3. Ahora puedes intentar crear un nuevo número, resumir un repositorio o obtener información sobre tu trabajo usando prompts en lenguaje natural.
    
4. Sigue las indicaciones en Copilot Chat para completar tus tareas de forma eficiente.
    

## Capacidades agentes del Copilot y MCP

Hasta ahora, hemos visto cómo los servidores MCP amplían GitHub Copilot conectándolo a herramientas y recursos externos. Pero, ¿qué ocurre cuando combinamos esto con el modo agente? Aquí es donde Copilot pasa de ser solo un asistente receptivo a actuar más como un colaborador independiente.

### ¿Qué son las capacidades agentes?

Las capacidades agenticas otorgan al Copilot la capacidad de:

- Trabaja de forma independiente realizando flujos de trabajo en varios pasos sin necesidad de guía constante.
    
- Toma decisiones eligiendo qué herramientas o enfoques usar según el contexto que tiene. Adáptate y mejora respondiendo a los comentarios, ajustando su enfoque e iterando sobre los resultados.
    

En otras palabras, el modo agente permite a Copilot gestionar las tareas de una manera que resulta más autónoma, casi como tener un compañero que entiende el panorama general en lugar de seguir instrucciones individuales.

### Cómo MCP hace que el modo Agente sea más fuerte

Por sí solo, el modo agente es poderoso. Pero cuando añades servidores MCP, le das a Copilot la capacidad de ir más allá del entorno inmediato de codificación. A través de MCP, Copilot puede:

- Accede directamente a datos externos, APIs o herramientas empresariales.
- Mantente en contexto en múltiples plataformas, sin tener que cambiar de aplicación.
- Completar "bucles agenticos", donde busca información dinámicamente, analiza resultados y da pasos informados, todo sin reiniciar el proceso desde cero.

Esto significa que Copilot no reacciona solo a un solo prompt. En cambio, funciona en un ciclo: explorar, adaptarse y refinar hasta que produce el resultado que deseas.

### Ventajas de combinar MCP con Modo Agente

Cuando combinas estas dos capacidades, desbloqueas ventajas clave:

- **Contexto ampliado**: Copilot puede recurrir a información de varios sistemas, no solo de tu editor de código.
    
- **Reducción del esfuerzo manual**: El trabajo rutinario como abrir incidencias, gestionar flujos de trabajo o realizar comprobaciones puede automatizarse mientras te centras en decisiones de mayor valor.
    
- **Integración fluida**: Copilot puede realizar tareas que abarcan herramientas y plataformas, sin necesidad de conectores personalizados ni cambios constantes.
    

### Mejores prácticas para el éxito

Para sacar el máximo partido al MCP y al modo agente, prueba estas estrategias:

- **Sé claro con los objetivos**: define qué quieres que consiga Copilot y cómo debe ser el resultado final.
- **Proporciona contexto**: Comparte detalles de tu proyecto o flujo de trabajo. Esto puede incluir enlaces, referencias o pasos previos.
- **Establece límites**: Si quieres que Copilot se quede en la planificación (y que no haga cambios todavía), explícalo. También puedes limitar qué herramientas MCP están activas.
- **Pide confirmación: Antes de grandes** cambios, haz que Copilot resuma su plan para poder aprobarlo o perfeccionarlo.
- **Utiliza archivos de prompt o instrucciones**: Crea archivos de prompt personalizados que guíen a Copilot sobre cómo comportarse con servidores MCP específicos. Esto mantiene su comportamiento coherente y alineado con tus flujos de trabajo.
