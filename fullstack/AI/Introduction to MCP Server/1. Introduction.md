El GitHub MCP Server es una forma alojada, segura y escalable de integrar tus funciones favoritas de GitHub en tu flujo de trabajo asistido por IA. Construido sobre el Model Context Protocol (MCP), introducido por Anthropic, es compatible con todas tus herramientas de desarrollo favoritas.

Su suite de herramientas amplía GitHub Copilot y otras herramientas de IA para ayudarte a automatizar tareas, gestionar repositorios y mejorar tu experiencia de desarrollo con asistencia de IA contextualizada.

GitHub MCP Server te ayuda a empezar rápido manteniendo tu flujo de trabajo simple y enfocado. Está disponible para Visual Studio Code y se expandirá a otros editores y plataformas, ayudándote a llevar la productividad impulsada por IA a todo tu proceso de desarrollo.

## Objetivos de aprendizaje

Al final de este módulo, podrás hacerlo:

- Entiende qué son MCP y GitHub MCP Server y por qué son útiles para los desarrolladores.
    
- Configura y configura GitHub MCP Server en Visual Studio Code para tus proyectos.
    
- Utiliza el servidor MCP de GitHub con Copilot Chat para automatizar tareas de desarrollo.
    
- Identifica y resuelve problemas comunes al trabajar con GitHub MCP Server.
    

## Requisitos previos

Antes de empezar, asegúrate de tener lo siguiente:

- Una cuenta de GitHub
    
- Visual Studio Code u otro editor que soporte integración MCP
    
- Si eres miembro de una organización o empresa con un plan Copilot Business o Copilot Enterprise, la política de "servidores MCP en Copilot" debe estar habilitada para poder usar MCP con Copilot.
    

(Opcional)

- Un GitHub Personal Access Token (PAT) para configuración avanzada y control de permisos.
    
- Docker instalado si planeas experimentar con una configuración de servidor local para control práctico.
