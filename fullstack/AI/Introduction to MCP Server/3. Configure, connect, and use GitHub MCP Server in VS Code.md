En esta unidad, aprenderás a configurar y usar GitHub MCP Server en Visual Studio Code para poder incorporar flujos de trabajo impulsados por IA directamente a tu entorno de desarrollo. Aprenderás:

- Cómo configurar usando OAuth o un Token de Acceso Personal (PAT)
    
- Configuración local opcional usando Docker para mayor control
    
- Cómo usar el servidor MCP de GitHub con Copilot Chat para una productividad impulsada por IA
    
- Pasos comunes para la resolución de problemas
    

## Configurar el servidor GitHub MCP en VS Code

### Usa OAuth

Ahora que sabes lo que puede hacer GitHub MCP Server, vamos a explicar cómo configurarlo en Visual Studio Code para que puedas empezar a usarlo de inmediato. Esto te permitirá integrar tus flujos de trabajo preferidos impulsados por IA directamente en tu entorno de programación sin configuraciones complicadas.

1. En Visual Studio Code, abre la Paleta de Comandos pulsando Ctrl+Shift+P (Windows/Linux) o Cmd+Shift+P (Mac).
2. Escribe MCP: añadir servidor y pulsa Enter.
3. De la lista, selecciona **HTTP (HTTP o Eventos enviados por el servidor).**
4. En el campo **URL del servidor**, introduce [https://api.githubcopilot.com/mcp/](https://api.githubcopilot.com/mcp/), luego pulsa Enter.
5. Cuando se te pida introducir un **ID de servidor**, puedes pulsar Enter para usar el ID predeterminado o escribir un ID personalizado si lo prefieres.
6. Elige dónde quieres guardar la configuración de tu servidor MCP. Puedes añadirlo a la configuración de usuario para usarlo en todos los proyectos o a la configuración de tu espacio de trabajo para el proyecto actual.
7. Aparecerá un aviso pidiéndote autorizar con GitHub usando OAuth. **Selecciona Permitir** y inicia sesión en tu cuenta de GitHub si te lo piden.

Una vez configurado, GitHub MCP Server estará listo para usarse con tus proyectos en VS Code. Ahora puedes empezar a usar herramientas y flujos de trabajo impulsados por IA para automatizar tareas, gestionar problemas y analizar tu código directamente dentro de tu editor, ayudándote a mantener el foco en tu trabajo mientras GitHub MCP Server se encarga del trabajo pesado en segundo plano.

### Utilizar el Token de Acceso Personal

Para usar Personal Access Token (PAT) para control avanzado, puedes seguir estos pasos:

1. Crea un PAT con el repositorio y lee: packages scope en tu cuenta de GitHub.
    
2. Seguirás los mismos pasos anteriores, pero cancelarás OAuth cuando te lo pidan.
    
3. En tu archivo de configuración, añade:
    
    ```json
    "headers": {
	  "Authorization": "Bearer ${input:github_token}"
	}
    ```
    
4. A continuación, añade un prompt de entrada para introducir tu token de forma segura:
    
    ```json
    "inputs": [
	  {
	    "id": "github_token",
	    "type": "promptString",
	    "description": "GitHub Personal Access Token",
	    "password": true
	  }
	]
    ```
    
5. Por último, reinicia el servidor MCP en VS Code e introduce tu PAT cuando te lo pidan.
    
6. El servidor MCP ahora estará configurado para usar el PAT para la autorización.
    

## Configuración local del servidor MCP con Docker (opcional)

Si tu empresa utiliza GitHub Enterprise Server con restricciones de PAT, solo puedes acceder a los ámbitos de API permitidos por la política de tu organización. Si todos los endpoints están restringidos, el servidor MCP no estará disponible, consulta con tu administrador si no estás seguro.

Para uso local, el Servidor MCP requiere Docker y autenticación con un Token de Acceso Personal (PAT). OAuth no está soportado en este sistema.

1. Primero tienes que confirmar que Docker está instalado y funcionando en tu sistema.
    
2. A continuación, genera un PAT con los telescopios necesarios.
    
3. Utiliza la siguiente configuración para ejecutar el servidor localmente:

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "github_token",
      "description": "GitHub Personal Access Token",
      "password": true
    }
  ],
  "servers": {
    "github": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "-e",
        "GITHUB_PERSONAL_ACCESS_TOKEN",
        "ghcr.io/github/github-mcp-server"
      ],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "${input:github_token}"
      }
    }
  }
}
```
    
4. Reinicia el servidor MCP e introduce tu PAT cuando te pidan que completes la configuración.
    

## Resolución de problemas

Si encuentras problemas al usar GitHub MCP Server, aquí tienes algunas comprobaciones prácticas:

- Confirma que has iniciado sesión en tu cuenta de GitHub dentro de VS Code.
- Si usas un PAT, asegúrate de que tenga los osciloscopios correctos y que esté introducido correctamente.
- Revisa tu configuración para detectar errores tipográficos o campos que falten.
- Si usas Docker, asegúrate de que esté instalado y funcionando activamente.
- Prueba a reiniciar VS Code o el servidor MCP para resolver problemas de conexión temporal.
