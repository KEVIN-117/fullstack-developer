En los capítulos anteriores, hemos visto muchas herramientas que manipulan el texto. En este capítulo, nos centraremos en programas que están diseñados específicamente para procesar texto de diversas maneras.

Linux, fiel a su herencia Unix, tiene una rica colección de herramientas de procesamiento de texto. Estas herramientas pueden utilizarse para realizar tareas como dar formato a documentos, extraer datos de archivos de texto e incluso generar informes complejos.

En este capítulo, veremos los siguientes comandos:

**cat** - Concatenar archivos e imprimirlos en la salida estándar.

**sort** - Ordenar líneas de archivos de texto.

**uniq** - Informar u omitir líneas repetidas.

**cut** - Eliminar secciones de cada línea de archivos.

**paste** - Fusionar líneas de archivos.

**join** - Unir líneas de dos archivos en un campo común.

**comm** - Comparar dos archivos ordenados línea por línea.

**diff** - Comparar archivos línea por línea.

**patch** - Aplicar un archivo **diff** a un original.

**tr** - Traducir o borrar caracteres.

**sed** - Editor de flujo para filtrar y transformar texto.

**aspell** - Corrector ortográfico interactivo.

Ya hemos cubierto **cat**, **sort** y **uniq** en el Capítulo 6. Vamos a refrescar nuestra memoria y a ver algunas de sus capacidades más avanzadas.

### **cat — Recordatorio y Más**

El comando **cat** es la "navaja suiza" del procesamiento de texto. Ya sabemos que se utiliza para mostrar archivos y unirlos. Pero **cat** también tiene algunas opciones útiles para el procesamiento de texto (ver Tabla 20-1).

**Tabla 20-1:** Opciones de **cat**

| **Opción** | **Descripción** |
| --- | --- |
| `-A` | Muestra todos los caracteres, incluidos los caracteres no imprimibles como los tabuladores y los finales de línea. |
| `-n` | Numera todas las líneas de salida. |
| `-s` | Suprime las líneas en blanco repetidas. |
| `-T` | Muestra los caracteres de tabulación como `^I`. |
| `-v` | Muestra los caracteres no imprimibles. |

Ejemplo:

```bash
[me@linuxbox ~]$ cat -n distros.txt  
     1  Fedora 28 2018-05-01  
     2  Ubuntu 18.04 2018-04-26  
     3  SUSE 15 2018-05-22
```

### **sort — Ordenación Avanzada**

El comando **sort** es extremadamente potente. Puede ordenar datos basándose en campos específicos y manejar diferentes tipos de datos (como números).

Consideremos un archivo llamado *distros.txt* con el siguiente contenido:

```text
Fedora 28 2018-05-01  
Ubuntu 18.04 2018-04-26  
SUSE 15 2018-05-22
```

Podemos ordenar este archivo por la segunda columna (la versión) utilizando la opción `-k`:

```bash
[me@linuxbox ~]$ sort -k 2 distros.txt  
SUSE 15 2018-05-22  
Ubuntu 18.04 2018-04-26  
Fedora 28 2018-05-01
```

Si los datos fueran numéricos, utilizaríamos la opción `-n` para asegurar una ordenación numérica correcta en lugar de alfabética.

### **uniq — Eliminando Duplicados**

Ya sabemos que **uniq** elimina las líneas duplicadas de un archivo *ordenado*. También puede utilizarse con la opción `-c` para contar el número de veces que aparece cada línea.

```bash
[me@linuxbox ~]$ sort distros.txt | uniq -c
```

### **Extrayendo y Fusionando Texto**

#### **_cut_**

El comando **cut** se utiliza para extraer secciones (campos) de cada línea de un archivo. Es especialmente útil cuando se trabaja con archivos delimitados (como archivos CSV o */etc/passwd*).

Por ejemplo, para extraer el nombre de usuario y el directorio personal del archivo */etc/passwd*:

```bash
[me@linuxbox ~]$ cut -d ':' -f 1,6 /etc/passwd
```

Aquí, `-d` especifica el delimitador (`:`) y `-f` especifica los campos que queremos extraer (1 y 6).

#### **_paste_**

El comando **paste** es lo contrario de **cut**. Fusiona líneas de varios archivos.

```bash
[me@linuxbox ~]$ paste archivo1.txt archivo2.txt
```

#### **_join_**

El comando **join** es similar a **paste** pero más inteligente. Une líneas de dos archivos basándose en un campo común (similar a una operación JOIN en SQL). Ambos archivos deben estar ordenados por el campo de unión.

```bash
[me@linuxbox ~]$ join distros.txt versiones.txt
```

### **Comparando Texto**

#### **_comm_**

El programa **comm** compara dos archivos de texto ordenados y muestra tres columnas: líneas únicas del archivo 1, líneas únicas del archivo 2 y líneas comunes a ambos.

```bash
[me@linuxbox ~]$ comm archivo1.txt archivo2.txt
```

#### **_diff_**

El programa **diff** es una herramienta mucho más potente para encontrar las diferencias entre dos archivos. Se utiliza habitualmente en el desarrollo de software para crear archivos de "parche" (*patch files*).

```bash
[me@linuxbox ~]$ diff archivo1.txt archivo2.txt
```

La salida de **diff** puede ser un poco difícil de leer al principio, pero describe los cambios necesarios para convertir el archivo 1 en el archivo 2.

#### **_patch_**

El programa **patch** se utiliza para aplicar los cambios descritos en un archivo **diff** a un archivo original.

```bash
[me@linuxbox ~]$ diff archivo_viejo archivo_nuevo > cambios.diff  
[me@linuxbox ~]$ patch archivo_viejo < cambios.diff
```

### **Edición de Texto sobre la Marcha**

#### **_tr_**

El comando **tr** (*translate*) se utiliza para traducir o borrar caracteres. No lee archivos directamente; toma su entrada de *stdin*.

Por ejemplo, para convertir un texto a mayúsculas:

```bash
[me@linuxbox ~]$ echo "hola mundo" | tr 'a-z' 'A-Z'  
HOLA MUNDO
```

Para borrar los caracteres de retorno de carro de un archivo de Windows:

```bash
[me@linuxbox ~]$ tr -d '\r' < archivo_windows.txt > archivo_linux.txt
```

#### **_sed_**

El comando **sed** (*stream editor*) es uno de los programas más potentes (y complejos) de Linux. Se utiliza para realizar transformaciones de texto en un flujo de datos.

El uso más común de **sed** es el buscar y reemplazar. Por ejemplo, para cambiar todas las apariciones de "viejo" por "nuevo" en un archivo:

```bash
[me@linuxbox ~]$ sed 's/viejo/nuevo/g' archivo.txt
```

**sed** puede hacer muchísimas más cosas, como borrar líneas, insertar texto y realizar sustituciones complejas utilizando expresiones regulares. Cubriremos **sed** con más detalle en un capítulo posterior del libro.

#### **_aspell_**

Por último, **aspell** es un corrector ortográfico interactivo de línea de comandos. Puede utilizarse para comprobar y corregir la ortografía de archivos de texto.

```bash
[me@linuxbox ~]$ aspell check documento.txt
```

### **Resumiendo**

En este capítulo, hemos visto una pequeña muestra de la increíble potencia que Linux ofrece para el procesamiento de texto. Estas herramientas pueden combinarse mediante tuberías para realizar tareas de manipulación de datos extremadamente sofisticadas. Aunque algunos de estos comandos (como **sed**) tienen una curva de aprendizaje pronunciada, la inversión merece la pena.
