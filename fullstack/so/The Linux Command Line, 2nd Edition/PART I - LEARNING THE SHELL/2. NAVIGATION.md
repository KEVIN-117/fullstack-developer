Lo primero que tenemos que aprender (además de cómo escribir) es cómo navegar por el sistema de archivos de nuestro sistema Linux. En este capítulo, introduciremos los siguientes comandos:

**pwd** - Imprime el nombre del directorio de trabajo actual.

**cd** - Cambia de directorio.

**ls** - Lista el contenido de un directorio.

### **Comprendiendo el árbol del sistema de archivos**

Al igual que Windows, un sistema operativo tipo Unix como Linux organiza sus archivos en lo que se denomina una *estructura de directorios jerárquica*. Esto significa que están organizados en un patrón de árbol de directorios (a veces llamados *carpetas* en otros sistemas), que pueden contener archivos y otros directorios. El primer directorio del sistema de archivos se llama *directorio raíz*. El directorio raíz contiene archivos y subdirectorios, que a su vez contienen más archivos y subdirectorios, y así sucesivamente.

Ten en cuenta que, a diferencia de Windows, que tiene un árbol de archivos separado para cada dispositivo de almacenamiento, los sistemas tipo Unix como Linux siempre tienen un único árbol de archivos, independientemente de cuántos discos o dispositivos de almacenamiento estén conectados al ordenador. Los dispositivos de almacenamiento se conectan (o más correctamente, *montan*) en varios puntos del árbol según los criterios del *administrador del sistema*, la persona (o personas) responsable del mantenimiento del sistema.

### **El Directorio de Trabajo Actual**

La mayoría de nosotros probablemente estemos familiarizados con un gestor gráfico de archivos que representa el árbol del sistema de archivos, como se ilustra en la Figura 2-1.

![Imagen](https://learning.oreilly.com/api/v2/epubs/urn:orm:book:9781492071235/files/images/02fig01.jpg)

*Figura 2-1: Árbol del sistema de archivos mostrado por un gestor gráfico de archivos*

Observa que el árbol suele aparecer invertido, es decir, con la raíz en la parte superior y las distintas ramas descendiendo por debajo.

Sin embargo, la línea de comandos no tiene imágenes, así que para navegar por el árbol del sistema de archivos, hay que verlo de otra manera.

Imagina que el sistema de archivos es un laberinto con forma de árbol invertido y que podemos situarnos en medio de él. En cualquier momento, estamos dentro de un único directorio, y podemos ver los archivos contenidos en el directorio y la ruta hacia el directorio que está arriba (llamado *directorio padre*) y cualquier subdirectorio que esté debajo. El directorio en el que estamos se llama *directorio de trabajo actual*. Para mostrar el directorio de trabajo actual, usamos el comando **pwd** (*print working directory*).

```bash
[me@linuxbox ~]$ pwd  
/home/me
```

Cuando iniciamos sesión en nuestro sistema (o iniciamos una sesión de emulador de terminal), nuestro directorio de trabajo actual está configurado como nuestro directorio personal (*home*). A cada cuenta de usuario se le asigna su propio directorio personal, y es el único lugar donde un usuario normal puede escribir archivos.

### **Listado del contenido de un directorio**

Para listar los archivos y directorios en el directorio de trabajo actual, usamos el comando **ls**.

```bash
[me@linuxbox ~]$ ls  
Desktop Documents Music Pictures Public Templates Videos
```

De hecho, podemos usar el comando **ls** para listar el contenido de cualquier directorio, no solo el directorio de trabajo actual, y hay muchas otras cosas interesantes que puede hacer también. Pasaremos más tiempo con **ls** en el Capítulo 3.

### **Cambiando el Directorio de Trabajo Actual**

Para cambiar nuestro directorio de trabajo (donde estamos en el laberinto en forma de árbol), usamos el comando **cd**. Para ello, escribe **cd** seguido del nombre de ruta (*pathname*) del directorio de trabajo deseado. Un nombre de ruta es la ruta que tomamos por las ramas del árbol para llegar al directorio que queremos. Podemos especificar nombres de ruta de dos maneras diferentes: como *nombres de ruta absolutos* o como *nombres de ruta relativos*. Primero hablemos de los nombres de ruta absolutos.

#### **_Nombres de Ruta Absolutos_**

Un nombre de ruta absoluto comienza con el directorio raíz y sigue el árbol rama por rama hasta completar la ruta hacia el directorio o archivo deseado. Por ejemplo, hay un directorio en tu sistema donde están instalados la mayoría de los programas del sistema. El nombre de ruta del directorio es */usr/bin*. Esto significa que desde el directorio raíz (representado por la barra inicial en el nombre de ruta) hay un directorio llamado *usr* que contiene un directorio llamado *bin*.

```bash
[me@linuxbox ~]$ cd /usr/bin  
[me@linuxbox bin]$ pwd  
/usr/bin  
[me@linuxbox bin]$ ls  
... Listado de muchos, muchos archivos ...
```

Ahora podemos ver que hemos cambiado el directorio de trabajo actual a */usr/bin* y que está lleno de archivos. ¿Has notado cómo ha cambiado el prompt del shell? Por comodidad, normalmente se configura para mostrar automáticamente el nombre del directorio de trabajo.

#### **_Nombres de Ruta Relativos_**

Donde un nombre de ruta absoluto comienza en el directorio raíz y conduce a su destino, un nombre de ruta relativo comienza en el directorio de trabajo. Para ello, utiliza un par de notaciones especiales para representar posiciones relativas en el árbol del sistema de archivos. Estas notaciones especiales son `.` (punto) y `..` (punto-punto).

La notación `.` se refiere al directorio de trabajo, y la notación `..` se refiere al directorio padre del directorio de trabajo. Así es como funciona. Cambiemos el directorio de trabajo a */usr/bin* otra vez.

```bash
[me@linuxbox ~]$ cd /usr/bin  
[me@linuxbox bin]$ pwd  
/usr/bin
```

Ahora digamos que queremos cambiar el directorio de trabajo al padre de */usr/bin*, que es */usr*. Podríamos hacerlo de dos maneras diferentes, ya sea con un nombre de ruta absoluto:

```bash
[me@linuxbox bin]$ cd /usr  
[me@linuxbox usr]$ pwd  
/usr
```

o con un nombre de ruta relativo:

```bash
[me@linuxbox bin]$ cd ..  
[me@linuxbox usr]$ pwd  
/usr
```

Dos métodos diferentes con resultados idénticos. ¿Cuál deberíamos usar? ¡El que requiera teclear menos!

Del mismo modo, podemos cambiar el directorio de trabajo de */usr* a */usr/bin* de dos maneras diferentes, ya sea usando un nombre de ruta absoluto:

```bash
[me@linuxbox usr]$ cd /usr/bin  
[me@linuxbox bin]$ pwd  
/usr/bin
```

o usando un nombre de ruta relativo:

```bash
[me@linuxbox usr]$ cd ./bin  
[me@linuxbox bin]$ pwd  
/usr/bin
```

Ahora, hay algo importante que señalar aquí. En casi todos los casos, podemos omitir la parte `./` porque está implícita. Escribir lo siguiente hace lo mismo:

```bash
[me@linuxbox usr]$ cd bin
```

En general, si no especificamos un nombre de ruta para algo, se asumirá el directorio de trabajo.

**DATOS IMPORTANTES SOBRE LOS NOMBRES DE ARCHIVOS**

En sistemas Linux, los archivos se nombran de manera similar a otros sistemas como Windows, pero existen algunas diferencias importantes.

- **Los nombres de archivo que comienzan con un carácter de punto están ocultos.** Esto solo significa que `ls` no los listará a menos que uses `ls -a`. Cuando se creó tu cuenta, se colocaron varios archivos ocultos en tu directorio personal para configurar cosas para tu cuenta. En el Capítulo 11 analizaremos más de cerca algunos de estos archivos para ver cómo puedes personalizar tu entorno. Además, algunas aplicaciones colocan sus archivos de configuración en tu directorio personal como archivos ocultos.
- **Los nombres de archivo y los comandos en Linux, como en Unix, son sensibles a mayúsculas y minúsculas (*case-sensitive*).** Los nombres de archivo *Archivo1* y *archivo1* se refieren a archivos diferentes.
- **Aunque Linux admite nombres de archivo largos que pueden contener espacios incrustados y caracteres de puntuación, limita los caracteres de puntuación en los nombres de los archivos que crees a punto, guion y guion bajo.** *Lo más importante: no incluyas espacios en los nombres de archivos.* Si quieres representar espacios entre palabras en un nombre de archivo, usa caracteres de guion bajo. Te lo agradecerás más adelante.
- **Linux no tiene el concepto de "extensión de archivo" como otros sistemas operativos.** Puedes nombrar los archivos como quieras. El contenido o propósito de un archivo se determina por otros medios. Aunque los sistemas operativos tipo Unix no utilizan extensiones de archivo para determinar el contenido o propósito de los archivos, muchos programas de aplicación sí lo hacen.

#### **_Algunos atajos útiles_**

La Tabla 2-1 muestra algunas formas útiles de cambiar rápidamente el directorio de trabajo actual.

**Tabla 2-1:** Atajos de cd

| **Atajo** | **Resultado** |
| --- | --- |
| `cd` | Cambia el directorio de trabajo a tu directorio personal (*home*). |
| `cd -` | Cambia el directorio de trabajo al directorio de trabajo anterior. |
| `cd ~nombre_usuario` | Cambia el directorio de trabajo al directorio personal de *nombre_usuario*. Por ejemplo, `cd ~bob` cambiará al directorio personal del usuario "bob". |
