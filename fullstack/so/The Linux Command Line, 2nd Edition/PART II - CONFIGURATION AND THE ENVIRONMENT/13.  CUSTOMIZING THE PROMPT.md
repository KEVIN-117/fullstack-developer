En este capítulo, veremos un detalle aparentemente trivial: nuestro indicador del shell (*prompt*). Este examen revelará parte del funcionamiento interno del shell y del programa emulador de terminal.

Como tantas cosas en Linux, el indicador del shell es altamente configurable y, aunque lo hemos dado prácticamente por sentado, el *prompt* es un dispositivo realmente útil una vez que aprendemos a controlarlo.

### **Anatomía de un Prompt**

Nuestro *prompt* por defecto se ve algo así:

`[me@linuxbox ~]$`

Observa que contiene nuestro nombre de usuario, nuestro nombre de host y nuestro directorio de trabajo actual, pero ¿cómo ha llegado a ser así? Resulta que de forma muy sencilla. El *prompt* viene definido por una variable de entorno llamada **PS1** (abreviatura de "prompt string 1"). Podemos ver el contenido de **PS1** con el comando **echo**.

```bash
[me@linuxbox ~]$ echo $PS1  
[\u@\h \W]\$
```

**NOTA**

_No te preocupes si tus resultados no son los mismos que los de este ejemplo. Cada distribución de Linux define la cadena del prompt de forma un poco diferente, algunas de forma bastante exótica._

A partir de los resultados, podemos ver que **PS1** contiene algunos de los caracteres que vemos en nuestro prompt, como los corchetes, la arroba y el signo de dólar, pero el resto es un misterio. Los más astutos reconocerán estos caracteres como *caracteres especiales escapados por barra invertida*, como los que vimos en el Capítulo 7. La Tabla 13-1 proporciona una lista parcial de los caracteres que **bash** trata de forma especial en la cadena del prompt.

**Tabla 13-1:** Códigos de Escape Utilizados en los Prompts del Shell

| **Secuencia** | **Valor mostrado** |
| --- | --- |
| `\a` | Campana ASCII. Hace que el ordenador emita un pitido cuando se encuentra. |
| `\d` | Fecha actual en formato día, mes, fecha. Por ejemplo, "Mon May 26". |
| `\h` | Nombre de host de la máquina local menos el nombre de dominio final. |
| `\H` | Nombre de host completo. |
| `\j` | Número de trabajos que se ejecutan en la sesión de shell actual. |
| `\l` | Nombre del dispositivo de terminal actual. |
| `\n` | Un carácter de salto de línea. |
| `\r` | Un retorno de carro. |
| `\s` | Nombre del programa de shell. |
| `\t` | Hora actual en formato de 24 horas: minutos:segundos. |
| `\T` | Hora actual en formato de 12 horas. |
| `\@` | Hora actual en formato de 12 horas AM/PM. |
| `\A` | Hora actual en formato de 24 horas: minutos. |
| `\u` | Nombre del usuario actual. |
| `\v` | Número de versión del shell. |
| `\V` | Números de versión y lanzamiento del shell. |
| `\w` | Nombre del directorio de trabajo actual. |
| `\W` | Última parte del nombre del directorio de trabajo actual. |
| `\!` | Número de historial del comando actual. |
| `\#` | Número de comandos introducidos durante esta sesión de shell. |
| `\$` | Muestra un carácter `$` a menos que tengamos privilegios de superusuario. En ese caso, muestra un `#` en su lugar. |
| `\[` | Indica el inicio de una serie de uno o más caracteres no imprimibles. Se utiliza para incrustar caracteres de control no imprimibles que manipulan el emulador de terminal de alguna manera, como mover el cursor o cambiar los colores del texto. |
| `\]` | Indica el final de una secuencia de caracteres no imprimibles. |

### **Probando Algunos Diseños de Prompt Alternativos**

Con esta lista de caracteres especiales, podemos cambiar el prompt para ver el efecto. En primer lugar, haremos una copia de seguridad de la cadena del prompt existente para poder restaurarla más tarde. Para ello, copiaremos la cadena existente en otra variable del shell que crearemos nosotros mismos.

```bash
[me@linuxbox ~]$ ps1_old="$PS1"
```

Creamos una nueva variable llamada `ps1_old` y le asignamos el valor de **PS1**. Podemos verificar que la cadena se ha copiado utilizando el comando **echo**.

```bash
[me@linuxbox ~]$ echo $ps1_old  
[\u@\h \W]\$
```

Podemos restaurar el prompt original en cualquier momento durante nuestra sesión de terminal simplemente invirtiendo el proceso.

```bash
[me@linuxbox ~]$ PS1="$ps1_old"
```

Ahora que estamos listos para proceder, veamos qué sucede si tenemos una cadena de prompt vacía.

```bash
[me@linuxbox ~]$ PS1=
```

Si no asignamos nada a la cadena del prompt, no obtenemos nada. ¡Ninguna cadena de prompt en absoluto! El prompt sigue ahí pero no muestra nada, tal como le pedimos que hiciera. Como esto resulta un poco desconcertante de ver, lo sustituiremos por un prompt mínimo.

`PS1="\$ "`

Así está mejor. Al menos ahora podemos ver lo que estamos haciendo. Observa el espacio final dentro de las comillas dobles. Esto proporciona el espacio entre el signo de dólar y el cursor cuando se muestra el prompt.

Añadamos una campana a nuestro prompt.

`$ PS1="\[\a\]\$ "`

Ahora deberíamos oír un pitido cada vez que se muestre el prompt, aunque algunos sistemas desactivan esta "característica". Esto podría llegar a ser molesto, pero podría ser útil si necesitáramos una notificación cuando se ha ejecutado un comando especialmente largo. Observa que incluimos las secuencias `\[` y `\]`. Dado que la campana ASCII (`\a`) no se "imprime", es decir, no mueve el cursor, necesitamos decírselo a **bash** para que pueda determinar correctamente la longitud del prompt.

A continuación, intentemos hacer un prompt informativo con algo de información sobre el nombre del host y la hora del día.

```bash
$ PS1="\A \h \$ "  
17:33 linuxbox $
```

Añadir la hora del día a nuestro prompt será útil si necesitamos llevar la cuenta de cuándo realizamos ciertas tareas. Por último, haremos un nuevo prompt similar al original.

```bash
17:37 linuxbox $ PS1="<\u@\h \W>\$ "  
<me@linuxbox ~>$
```

Prueba las otras secuencias enumeradas en la Tabla 13-1 y comprueba si se te ocurre un nuevo y brillante prompt.

### **Añadiendo Color**

La mayoría de los programas emuladores de terminal responden a ciertas secuencias de caracteres no imprimibles para controlar cosas como los atributos de los caracteres (como el color, el texto en negrita y el temido texto parpadeante) y la posición del cursor. Cubriremos la posición del cursor en un momento, pero primero veremos el color.

**CONFUSIÓN DE TERMINALES**

En los tiempos antiguos, cuando las terminales estaban conectadas a ordenadores remotos, había muchas marcas de terminales que competían entre sí, y todas funcionaban de forma diferente. Tenían teclados diferentes y todas tenían formas diferentes de interpretar la información de control. Unix y los sistemas tipo Unix tienen dos subsistemas bastante complejos para tratar con la babel del control de terminales (llamados *termcap* y *terminfo*). Si buscas en los rincones más profundos de la configuración de tu emulador de terminal, podrías encontrar un ajuste para el tipo de emulación de terminal.

En un esfuerzo por hacer que las terminales hablaran algún tipo de lenguaje común, el Instituto Nacional Estadounidense de Estándares (ANSI) desarrolló un conjunto estándar de secuencias de caracteres para controlar las terminales de vídeo. Los antiguos usuarios de DOS recordarán el archivo *ANSI.SYS* que se utilizaba para habilitar la interpretación de estos códigos.

El color de los caracteres se controla enviando al emulador de terminal un *código de escape ANSI* incrustado en el flujo de caracteres que se van a mostrar. El código de control no se "imprime" en la pantalla, sino que la terminal lo interpreta como una instrucción. Como vimos en la Tabla 13-1, las secuencias `\[` y `\]` se utilizan para encapsular caracteres no imprimibles. Un código de escape ANSI comienza con un 033 octal (el código generado por la tecla **ESC**), seguido de un atributo de carácter opcional, seguido de una instrucción. Por ejemplo, el código para establecer el color del texto a normal (atributo = 0), texto negro es el siguiente:

`\033[0;30m`

La Tabla 13-2 enumera los colores de texto disponibles. Observa que los colores se dividen en dos grupos, diferenciados por la aplicación del atributo de carácter en negrita (1), que crea la apariencia de colores "claros".

**Tabla 13-2:** Secuencias de Escape Utilizadas para Establecer los Colores del Texto

| **Secuencia** | **Color del texto** | **Secuencia** | **Color del texto** |
| --- | --- | --- | --- |
| `\033[0;30m` | Negro | `\033[1;30m` | Gris oscuro |
| `\033[0;31m` | Rojo | `\033[1;31m` | Rojo claro |
| `\033[0;32m` | Verde | `\033[1;32m` | Verde claro |
| `\033[0;33m` | Marrón | `\033[1;33m` | Amarillo |
| `\033[0;34m` | Azul | `\033[1;34m` | Azul claro |
| `\033[0;35m` | Púrpura | `\033[1;35m` | Púrpura claro |
| `\033[0;36m` | Cian | `\033[1;36m` | Cian claro |
| `\033[0;37m` | Gris claro | `\033[1;37m` | Blanco |

Intentemos hacer un prompt rojo (visto aquí como gris). Insertaremos el código de escape al principio.

```bash
<me@linuxbox ~>$ PS1="\[\033[0;31m\]<\u@\h \W>\$ "  
<me@linuxbox ~>$
```

Eso funciona, pero observa que todo el texto que escribamos después del prompt se mostrará también en rojo. Para solucionar esto, añadiremos otro código de escape al final del prompt que le indique al emulador de terminal que vuelva al color anterior.

```bash
<me@linuxbox ~>$ PS1="\[\033[0;31m\]<\u@\h \W>\$\[\033[0m\] "  
<me@linuxbox ~>$
```

¡Así está mejor!

También es posible establecer el color de fondo del texto utilizando los códigos que figuran en la Tabla 13-3. Los colores de fondo no admiten el atributo de negrita.

**Tabla 13-3:** Secuencias de Escape Utilizadas para Establecer el Color de Fondo

| **Secuencia** | **Color de fondo** |
| --- | --- |
| `\033[0;40m` | Negro |
| `\033[0;41m` | Rojo |
| `\033[0;42m` | Verde |
| `\033[0;43m` | Marrón |
| `\033[0;44m` | Azul |
| `\033[0;45m` | Púrpura |
| `\033[0;46m` | Cian |
| `\033[0;47m` | Gris claro |

Podemos crear un prompt con fondo rojo aplicando un sencillo cambio al primer código de escape.

```bash
<me@linuxbox ~>$ PS1="\[\033[0;41m\]<\u@\h \W>\$\[\033[0m\] "  
<me@linuxbox ~>$
```

¡Prueba los códigos de color y mira qué puedes crear!

**NOTA**

_Además de los atributos de carácter normal (0) y negrita (1), el texto puede tener atributos de subrayado (4), parpadeo (5) e inverso (7). Sin embargo, en interés del buen gusto, muchos emuladores de terminal se niegan a respetar el atributo de parpadeo._

### **Moviendo el Cursor**

Los códigos de escape pueden utilizarse para posicionar el cursor. Esto se utiliza habitualmente para proporcionar un reloj o algún otro tipo de información en una ubicación diferente de la pantalla, como en una esquina superior cada vez que se dibuja el prompt. La Tabla 13-4 enumera los códigos de escape que posicionan el cursor.

**Tabla 13-4:** Secuencias de Escape de Movimiento del Cursor

| **Código de escape** | **Acción** |
| --- | --- |
| `\033[l;cH` | Mueve el cursor a la línea *l* y a la columna *c* |
| `\033[nA` | Mueve el cursor *n* líneas hacia arriba |
| `\033[nB` | Mueve el cursor *n* líneas hacia abajo |
| `\033[nC` | Mueve el cursor *n* caracteres hacia adelante |
| `\033[nD` | Mueve el cursor *n* caracteres hacia atrás |
| `\033[2J` | Limpia la pantalla y mueve el cursor a la esquina superior izquierda (línea 0, columna 0) |
| `\033[K` | Limpia desde la posición del cursor hasta el final de la línea actual |
| `\033[s` | Almacena la posición actual del cursor |
| `\033[u` | Recupera la posición almacenada del cursor |

Utilizando los códigos de la Tabla 13-4, construiremos un prompt que dibuje una barra roja en la parte superior de la pantalla que contenga un reloj (representado en texto amarillo) cada vez que se muestre el prompt. El código del prompt es esta cadena de aspecto formidable:

`PS1="\[\033[s\033[0;0H\033[0;41m\033[K\033[1;33m\t\033[0m\033[u\]<\u@\h \W>\$ "`

La Tabla 13-5 resume lo que hace cada parte de la cadena.

**Tabla 13-5:** Desglose de la Cadena de Prompt Compleja

| **Secuencia** | **Acción** |
| --- | --- |
| `\[` | Inicia una secuencia de caracteres no imprimibles. El propósito de esto es permitir que **bash** calcule correctamente el tamaño del prompt visible. Sin un cálculo preciso, las funciones de edición de la línea de comandos no pueden posicionar el cursor correctamente. |
| `\033[s` | Almacena la posición del cursor. Esto es necesario para volver a la ubicación del prompt después de que la barra y el reloj se hayan dibujado en la parte superior de la pantalla. Ten en cuenta que algunos emuladores de terminal no reconocen este código. |
| `\033[0;0H` | Mueve el cursor a la esquina superior izquierda, que es la línea 0, columna 0. |
| `\033[0;41m` | Establece el color de fondo en rojo. |
| `\033[K` | Limpia desde la ubicación actual del cursor (la esquina superior izquierda) hasta el final de la línea. Como el color de fondo es ahora rojo, la línea se limpia con ese color, creando nuestra barra. Observa que limpiar hasta el final de la línea no cambia la posición del cursor, que permanece en la esquina superior izquierda. |
| `\033[1;33m` | Establece el color del texto en amarillo. |
| `\t` | Muestra la hora actual. Aunque se trata de un elemento "imprimible", lo incluimos igualmente en la parte no imprimible del prompt, ya que no queremos que **bash** incluya el reloj al calcular el tamaño real del prompt mostrado. |
| `\033[0m` | Desactiva el color. Esto afecta tanto al texto como al fondo. |
| `\033[u` | Restaura la posición del cursor guardada anteriormente. |
| `\]` | Termina la secuencia de caracteres no imprimibles. |
| `<\u@\h \W>\$` | Cadena del prompt. |

### **Guardando el Prompt**

Obviamente, no queremos estar escribiendo ese monstruo todo el tiempo, así que querremos guardar nuestro prompt en algún lugar. Podemos hacer que el prompt sea permanente añadiéndolo a nuestro archivo *.bashrc*. Para ello, añade estas dos líneas al archivo:

`PS1="\[\033[s\033[0;0H\033[0;41m\033[K\033[1;33m\t\033[0m\033[u\]<\u@\h \W>\$ "`  
  
`export PS1`

No todo el mundo se preocupará lo suficiente como para cambiar el prompt, ya que el prompt por defecto suele ser satisfactorio. Pero para aquellos de nosotros a los que nos gusta trastear, el shell ofrece la oportunidad de muchas horas de diversión casual.
